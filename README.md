## About Me

I'm a Full-Stack Web Developer and UI/UX Designer based in Phnom Penh, Cambodia. I build and ship production e-commerce platforms, internal workflow systems, and full-stack web applications — handling the work end to end, from data models and APIs to responsive, well-crafted user interfaces.

I started out in graphic design, moved into UI/UX and front-end development, and grew into full-stack web development. Today I work as a Website Developer and Team Lead, guiding a 4-person web team while designing and building systems that run in production.

**Core focus areas**

- End-to-end e-commerce website development
- Full-stack web systems — front-end, back-end, and database
- Internal workflow and team-management tools
- Product data management and structured CSV pipelines
- UI/UX design and reusable component systems
- AI-assisted development workflows
