## 👨‍💻 About Me

I'm **Seng Chhunsour**, a developer focused on turning ideas into polished, usable products.

I work across the entire product lifecycle:

`Idea → UX/UI → Frontend → Backend → Database → Testing → Deployment → Production`

My main focus is building software that solves practical problems — especially **SaaS platforms, mobile applications, internal business systems, dashboards, and digital commerce products**.
